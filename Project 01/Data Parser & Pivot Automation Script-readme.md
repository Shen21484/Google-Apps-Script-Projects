 # Warehouse Robotics Investment Efficiency Tracker

### Context:
To improve ROI, we established weekly audit of robotic assets across France. By analyzing volume distribution (throughput), we aimed to make data-driven decisions to maximize investment efficiency.

---
### Problem: 
The repetitive manual analysis on Google Sheets limits the time engineers have to devise actual efficiency solutions.

### Solution: 
Built an automated Google Apps Script tool that:

- Ingests & Cleans: Parses weekly data, extracting specific Robotic Finger IDs and categorizing them by vertical tiers (Level: Upper/Lower).

- Analyzes: Translated strategic business logic into machine-executable code, enabling automated processing of volume distribution metrics.

- Visualizes: Automatically generates Pivot Tables and Stacked Column Charts to highlight under-utilized assets.

### Impact: 
Enabled the operations team to balance workloads weekly and maximize the operational efficiency of the robotic fleet.
